# Assumptions and limitations

The source and configuration files contain modelling assumptions, material-property choices, operating conditions, and geometry-derived values. They must be reviewed against primary references before any scientific claim is treated as final.

- This is an exploratory computational study, not a validated safety analysis.
- The withheld DAGMC geometry prevents an independent full neutronics rerun from this repository alone.
- Thermal-hydraulics results are model-dependent and should be interpreted only within the stated one-dimensional framework.
- Compact result tables are retained for traceability; they are not experimental validation.
- The estimated finite-system multiplication factor applies an assumed leakage fraction to reflected single-block `k-infinity`; it is not a full-core transport result.
- Nothing in this repository should be used for reactor construction, operation, or licensing.
