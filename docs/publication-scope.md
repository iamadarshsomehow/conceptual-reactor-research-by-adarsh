# Publication scope

Included material is limited to final workflow source, compact result data, figures, and explanatory documentation.

The following are deliberately excluded pending separate review:

- DAGMC geometry (`.h5m`), CAD (`.step`/`.stp`), STL meshes, and VTK geometry exports;
- raw OpenMC statepoints, summaries, XML runtime exports, and tallies;
- virtual environments, build directories, third-party source clones, and caches;
- credentials, SSH material, personal configuration, and local paths;
- uncurated trial-and-error directories.

The remote repository will be created as private while detailed geometry and inputs undergo publication review.
