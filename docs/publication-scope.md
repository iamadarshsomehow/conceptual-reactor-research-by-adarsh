# Publication scope

Included material covers final workflow source, compact result data, figures, explanatory documentation, selected development source files, and the historical STEP CAD exports requested for the version archive.

The following are deliberately excluded pending separate review:

- DAGMC geometry (`.h5m`), generated STL meshes, and VTK geometry exports. Historical STEP files are included under `development/`;
- raw OpenMC statepoints, summaries, XML runtime exports, and tallies;
- virtual environments, build directories, third-party source clones, and caches;
- credentials, SSH material, personal configuration, and local paths;
- uncurated trial-and-error directories.

The GitHub repository is private while detailed geometry and inputs remain under publication review.
