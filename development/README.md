# Development versions and geometry

This archive preserves scripts and STEP CAD files from the successive model folders. Each folder includes a `NOTES.md` template for Adarsh to record what changed, why, and what was learned. The original version folder names are retained.

Included: 18 version/branch folders, their available Python/model source files and STEP geometry, plus standalone project STEP exports in `geometry/`. The three final workflow folders are represented in the main `neutronics/` and `thermal_hydraulics/` directories as well; version archives preserve their original scripts and geometry.

Excluded from this curated history: generated STL tessellations, OpenMC statepoints and summaries, build products, caches, and third-party library test data. Those accounted for most of the multi-gigabyte size of the original folders.
